## Entry

🌋 — one emoji, nothing else. A volcano: the dream vacation is standing on the rim of a living mountain, lava glowing below, at sunrise in Hawaii, Iceland, or Bromo. Vivid at a glance, specific, and a little surprising — not another beach.

## How to run

Requires Node 22.18+ (runs TypeScript directly, no install needed):

```sh
MAKEFUN_OUTPUT_DIR=/tmp/el-out node main.ts
cat /tmp/el-out/entry.txt
```

The program writes exactly the single emoji `🌋` (U+1F30B, one code point, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Deterministic, no network, Node stdlib only.
